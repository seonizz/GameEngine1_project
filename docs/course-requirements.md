# 수업 요구 사항 대조표

출처: 게임엔진1 8주차 중간고사 GDD 가이드 (https://creativeengineer-kimjungho.com/teaching/game-engine-1/week-08-midterm.html), 2026-11-09 확인.
상태 표기: 충족 / 보완 필요 / 미작성.

## 평가 기준 (중간고사 = 전체 성적 20%)
| 기준 | 질문 | v2에서 지킬 것 |
|---|---|---|
| 게임의 명확성 | 목표와 핵심 플레이가 분명한가 | 목표는 "인사 남기고 송별불로 귀환" 하나. 배웅은 선택 결과로만 표기해 목표를 흐리지 않는다 |
| 재미의 설득력 | 재미를 만드는 행동과 선택을 설명했는가 | 컵 실험(같은 얼굴 판별), 손잡기 유인, 옛 사진을 살필지의 선택을 선택·위험·보상 표로 설명 |
| 설계의 구체성 | 규칙과 화면 스케치가 구체적이며 서로 일치하는가 | 맵·화면 그림을 v2 배치(같은 얼굴 2명, 옛 사진, 등롱)로 다시 그리고 규칙표 좌표와 일치시킨다 |
| 계획의 현실성 | 학기 안에 완성 가능한가 | 수업 권장 일정(9~16주)에 맞춘 roadmap, 필수/선택/제외 구분 |

## 필수 10항목
| # | 항목 | v1 상태 | v2 보완 |
|---|---|---|---|
| 1 | 게임 개요 (한 문장 소개 포함) | 보완 필요 | 한 문장 소개 명시(story.md). 문서 앞에 **문서 버전·수정일** 추가 (v1 표지에 없음) |
| 2 | 기획 의도와 핵심 재미 | 보완 필요 | 선택·위험·보상 표에 "손을 내민 기다리는 이 바로 옆의 옛 사진에 다가가는가"(무섭지만 안전한 접근) 행 추가. 서사는 배경 3문장 + 대응표로만 |
| 3 | 핵심 플레이와 조작 | 충족 | 옛 사진 E 조작 허용 조건(송별 단계 ~ 풍경 전) 추가 |
| 4 | 게임 규칙과 상태 | 보완 필요 | 결말 2종 판정, 옛 사진 플래그, 우선순위 규칙 추가 |
| 5 | 레벨과 콘텐츠 | 보완 필요 | 맵 그림 갱신. **난이도 변화** 절 신설: 첫날 단일 반응 학습 → 사흘째 두 반응 비교 → 송별 순서 수행 |
| 6 | 플레이 화면과 UI | 보완 필요 | 결과 화면 2종, 옛 사진 클로즈업 패널 스케치 추가 |
| 7 | 아트·사운드와 에셋 | 보완 필요 | "직접 제작 128×192"를 외부 에셋 기준 규격(PPU)으로 교체, 에셋별 출처·이용 조건·대체안 |
| 8 | Unity 구현 계획 | 보완 필요 | 현재 프로토타입에서 **확인한 기능(근거)**과 **구현 계획**을 구분해 표기 (가이드 요구) |
| 9 | 개발 범위와 일정 | 보완 필요 | "착수 후 4주"를 수업 주차(11~16주) 기준으로 재작성. 결말 분기를 "진엔딩이 아닌 결과 분기"로 범위 설명 |
| 10 | 검증 기준과 제작 기록 | 보완 필요 | 검증 표에 상태 열(예정/확인 완료/수정 필요), 옛 사진·배웅 연출 관련 3행, 플레이테스트 기록, 출처, AI 활용, **변경 이력** |

## 문서 공통 요구
| 요구 | 상태 | 조치 |
|---|---|---|
| 분량: 표지·참고자료 제외 6~10쪽, 세계관보다 규칙·도식에 공간 | v1 약 9쪽 | v2는 서사를 1/2쪽 이내로 두고 10쪽을 넘기지 않는다 |
| 출처 기록 | 보완 필요 | 인용 번호 오류 수정(improvement-candidates D5), 에셋 출처 목록 |
| AI 사용: 활용 부분과 직접 수정·검증 내용 구분 | 보완 필요 | ChatGPT, Claude, Claude Code(+ mattpocock/skills)별로 "사용 범위 / 직접 수정·검증" 표 |
| 미완료 표시 | 미작성 | 테스트·기능마다 예정/확인 완료/수정 필요 |
| 변경 이력 | 미작성 | v1→v2 비교표(story.md 하단 + ADR 번호) |
| PDF 내보내기 후 표·글자·링크 잘림 확인 | 예정 | 최종 제출 전 점검 |

## 최종(16주) 제출물
실행 파일, Unity 프로젝트, 한 판 진행 영상, 제작 기록. 상세 GDD의 재제출 여부와 세부 배점·제출 경로는 별도 공지 확인 필요.

## 수업 권장 일정
| 주차 | 권장 결과물 |
|---|---|
| 9~10 | 블록아웃 보완, 아트 기준과 에셋 키트 준비 |
| 11~12 | 필수 규칙을 통합한 플레이 빌드 |
| 13 | 알파 빌드와 3인 플레이테스트 기록 |
| 14~15 | 면담 반영, 제출 후보 빌드, 기능 추가 종료 |
| 16 | 최종 실행 파일, 프로젝트, 영상, 제작 기록 제출 |

## 교수님·조교 확인 질문 (/to-questionnaire 입력)
1. 최종 제출 시 상세 GDD 개정본도 제출하는가, 제작 기록에 변경 이력만 포함하면 되는가?
2. 16주차 제출 일시와 경로, 영상 길이 기준
3. 외부 무료 에셋 사용 시 출처 표기 형식
4. 면담(14~15주) 일정과 준비물
