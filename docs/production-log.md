### v1 → v3 비교 (요약)
| 항목 | v1 (중간 GDD) | v3 (현재) |
|---|---|---|
| 시점·공간 | 2D 측면, 방 하나 | 탑다운 4방향 격자, 집 한 채(방 9개 + 마당·창고) |
| 분량 | 3~5분 | 목표 약 20분(측정 전) |
| 핵심 행동 | 컵·사진·풍경 조작, 관찰 | 소리를 내 아이를 움직이기(날마다 쓰임이 바뀜), 조사, 쫓김 |
| 판별·위협 | 가짜 가족의 시선(컵을 보는가, 나를 보는가) | 둘째 날 노크 방어, 사흘째 그것의 격자 추적 |
| 서사 | 돌아온 부모가 가짜를 거절하고 귀환 | 주인공이 얼굴을 잃은 옛 거주자였고, 쫓아오는 그것이 아이의 진짜 부모(반전) |
| 결말 | 성공 1(귀환), 실패 1(손잡기) | 4종: 배웅·빼앗은 불·남은 자리·꺼진 불 |

## 2. 날짜별 기록

### 2026-10-30 — 중간 GDD 제출
- v1 GDD 제출. 원문은 `docs/gdd-v1.md`에 보존(수정하지 않음).
- 제작자 메모: 작성 필요

### ~2026-11-09 — 측면 프로토타입, ADR 0001~0003
- v1 GDD 기준 측면 프로토타입(`GameFlow`, `ActorReaction`, `InteractableProp`, `UIController`, 씬 `Mukaebi.unity`).
- 서사 보강과 결말 구조 결정을 ADR 0001~0003으로 기록.
- 제작자 메모: 작성 필요

### 2026-11-10 — 측면 프로토타입 직접 플레이 → 탑다운으로 재설계
- 제작자가 측면 프로토타입을 직접 플레이하고 판단: "루즈하다", "가만히 있으면 다음 날로 넘어가는 데 오래 걸린다", "서사가 처음에 나오면 좋겠다", "지루하다".
- 원하는 방향: 쯔꾸르풍 탑다운, 그림자복도 분위기, 약 20분, 글은 적게, 반전이 있고 깔끔히 끝나는 결말.
- 결과: ADR 0004, 0005, 0006, story.md v3, 탑다운 프로토타입(48×32 지도). 측면 프로토타입은 참고용으로 남김.

### 2026-11-10 — 탑다운 프로토타입 직접 플레이(Unity Editor) → 조정
| 제작자 피드백 | 반영 |
|---|---|
| "마지막 3분이 너무 어렵다" | 소리 사슬 대신 상자 부르기(상자를 열면 아이가 상자로 오고 송별불 타이머가 멈춤) |
| "둘째 날 다음으로 넘어가는 법을 모르겠다" | 노크가 막든 열리든 다음으로 진행, 목표 줄에 결과와 "(n/3)" 표시, 노크 대상 깜빡임, 소리 물건 추가(불단 종·선풍기), 앞 칸 E 안내 |
| "미니맵이 있으면 좋겠다" | 미니맵(오른쪽 위, M 토글, 목표 점 깜빡임, 쫓아오는 그것은 표시 안 함) |
- 결정 기록: ADR 0007.
- 제작자 메모: 작성 필요

### 2026-11-11 — 문서 정리
- 문서를 v3 설계와 코드에 맞춤(1절 마지막 행).
- 문서 대조 중 발견한 결함 수정: 반전 후 선택창의 기본값과 Esc가 "비켜선다"(남은 자리 결말 확정)였다. 순서를 "그대로 있는다 / 비켜선다"로 바꿨다. Unity에서는 아직 확인하지 않음.
- 11/10에 요청된 미니맵이 첫 커밋에 빠져 있었던 것을 확인하고 별도 커밋으로 넣었다(AI 쪽 파일 전송 실수).
- Unity 없이 Core 테스트와 House 스크립트 컴파일을 확인하는 도구와 지도 생성 스크립트를 `tools/`에 넣었다.
