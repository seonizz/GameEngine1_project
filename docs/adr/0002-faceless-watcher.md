# 0002. 기다리는 이는 자기 얼굴이 없어 보는 이의 그리움을 비춘다

- 상태: 채택 (2026-11-09)
- 관련: docs/story.md, improvement-candidates C1·C3·C7

## 맥락
v1에서 가짜는 첫날에 없던 새 인물이라 컵 실험 전에 이미 의심할 수 있었다(D1). 또 혈연이 없는 옛 거주자가 왜 자녀의 모습인지 설명이 필요했다.

## 결정
- 기다리는 이는 기억해 주는 사람이 없어 자기 얼굴이 없고, 주인공에게는 자녀의 얼굴로 보인다.
- 사흘째에는 자녀와 기다리는 이가 같은 스프라이트로 등장한다. 외형으로 구분할 수 없으며 컵 실험이 유일한 판별 수단이다(C1 채택).
- 옛 사진 속 어른의 얼굴만 지워져 있다(단서와 규칙의 일치).
- 배웅 결말에서만 머리 스프라이트를 사진 속 얼굴로 교체한다.
- 산 사람은 기다리는 이를 볼 수 없다.
- 코드 이름은 기존 프로토타입의 `Watcher`를 유지한다.

## 열린 사항
- 두 인물의 배치를 고정할지, 판마다 바꿀지(재플레이 판별) — 그릴링에서 결정.
- 시선 표현(C3 눈동자 추적)은 인물 에셋 해상도 확인 후 결정.

## 결과
- 인물 스프라이트는 자녀 1종 + 사진 속 얼굴 머리 1종으로 충분하다(작업량 감소).
- 같은 외형이므로 시선 차이의 가독성이 판별의 전부가 된다. 1주차 프로토타입에서 가독성을 최우선 검증한다.
