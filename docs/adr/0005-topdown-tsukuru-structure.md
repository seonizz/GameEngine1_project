# 0005. 탑다운 쯔꾸르 구조, 20분 분량, 방 탐색과 추적으로 재구성한다

- 상태: 채택 (2026-11-10)
- 대체·수정: v1/v2의 "2D 측면 고정 시점", "방 하나", 범위 밖의 "추격 AI·여러 방". ADR 0004의 1번(측면 x 좌표 배치)은 탑다운 배치로 대체되고, 2~7번(고정 배치, 말풍선 제거, 방향 표시, 글 최소화, 동시 반응, 정답 문구 제거)은 유지한다.
- 관련: ADR 0002, 0003, 0004, docs/story.md

## 맥락
11/10 측면 프로토타입을 직접 플레이한 결과: "루즈하다", "가만히 있으면 다음 날로 넘어가는 데 오래 걸린다", "처음에 서사가 나왔으면 한다", "지루하다". 코드 기준 원인은 다음과 같다.
- 플레이어 행동이 E 한 번과 1초 서 있기뿐이다. 선택과 위험이 없다.
- 대기(전환 약 4초, 관찰 1초 × 구역 수)가 행동보다 길다.
- 방이 하나라 탐색·발견이 없다.
- 시선이 좌우 2값이라 판별 장면이 위치에 의존한다(ADR 0004 맥락).

제작자가 원하는 기준: 공포 쯔꾸르 감성(방을 돌아다니며 조사), 분위기는 그림자복도(어둠·쫓김), 한 판 약 20분, 글은 적고 분위기로 진행, 가벼운데 서사가 있고 깔끔히 끝나는 결말.

## 결정
1. 시점을 **탑다운 격자 이동**(4방향, 한 칸씩)으로 바꾼다. 집 한 채, 방 7개(현관, 복도, 불단 방, 거실·부엌, 자녀 방, 욕실, 창고, 안방).
2. 시선은 **4방향**이다. 판별 규칙: 대상까지의 방향(가로·세로 중 큰 축)과 플레이어까지의 방향이 다른 위치에서, 인물이 플레이어 쪽을 보고 있으면 "나를 본다"가 화면에서 읽힌다.
3. **조사**를 핵심 행동으로 둔다. 방마다 조사 대상 3~5개, 한 줄 문장. 서사는 대사가 아니라 조사 문장과 날마다 달라지는 집으로 전달한다.
4. **사흘째 추적**을 넣는다. 들킨 뒤 기다리는 이가 격자 최단 경로로 천천히 따라온다. 닿으면 "이번에는 가지 마." 손잡기 선택창이 뜬다. 거절하면 기다리는 이가 잠시 멈추고, 실패는 여전히 **손잡기 확정**뿐이다(ADR 0003 유지).
5. **분위기**: 전역 조명을 낮추고 주인공 주변의 희미한 빛과 불빛만 밝힌다(URP 2D Light). 벌레 소리·소화음 등 소리로 상태를 전달한다.
6. **오프닝**은 대사 없이 자녀가 마중불을 켜고 주인공이 문턱에 나타나는 연출로 시작한다.

## 20분 구성 (목표, 플레이테스트로 조정)
| 구간 | 시간 | 내용 |
|---|---|---|
| 오프닝 | 1분 | 8월 13일 밤. 자녀가 마중불을 켠다. 주인공이 문턱에 나타난다 |
| 첫날 | 6분 | 집 탐색과 조사(자녀가 혼자 지내는 흔적). 물건·소리로 자녀를 부르는 퍼즐 2개. 컵 실험으로 "산 사람은 물건을 본다" 학습 |
| 둘째 날 | 5분 | 집이 조금 달라짐(문이 열려 있음, 발소리). 창고에서 옛 거주자의 흔적. 복도 끝에서 같은 얼굴을 한 번 목격 |
| 사흘째 | 6분 | 같은 얼굴 둘, 컵 판별. 들키면 송별불이 꺼지고 추적 시작. 쫓기며 내 사진 인사, 옛 사진, 풍경 → 자녀가 불을 다시 켬 |
| 결말 | 1분 | 한 화면 문구로 닫음(배웅 / 남겨짐) |

## 범위 변경
- 허용으로 바뀜: 여러 방(한 집 안), 격자 최단 경로 추적(기다리는 이 1명).
- 계속 제외: 마을·2층·여러 스테이지, 인벤토리·물건 운반, 저장, 자유 물리, 회상 장면, 안내서 위조, 멀티플레이.

## 결과
- 기존 측면 프로토타입(Mukaebi 씬, GameFlow 등)은 참고용으로 남기고, 탑다운 코드는 `Assets/Scripts/House/`와 규칙 `Assets/Scripts/Core/`에 새로 만든다. 씬은 `Majungbul ▸ Build House Prototype`이 `Assets/Scenes/House.unity`로 생성한다.
- 중간 GDD의 시점·맵·범위 절이 바뀌므로 gdd-v2와 변경 이력에 반영한다.
- 위험: 분량이 약 4배가 된다. 11주차는 탐색·조사·판별·추적·송별의 뼈대, 12주차는 둘째 날과 퍼즐, 13주차 에셋·소리로 나눈다. 12주차 종료 시 첫날~사흘째가 이어지지 않으면 둘째 날을 줄인다.
- 에셋: 탑다운 일본식 실내 타일셋을 찾는다(docs/research/assets.md에 출처·이용 조건 기록 후 사용).
