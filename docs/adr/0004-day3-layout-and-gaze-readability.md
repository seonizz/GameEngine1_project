# 0004. 사흘째 판별 장면의 배치와 시선 표현을 프로토타입 기준으로 정한다

- 상태: 채택 (2026-11-10)
- 관련: ADR 0002, docs/story.md 5·9절, improvement-candidates C1·C3, roadmap 11주차

## 맥락
ADR 0002는 "같은 외형이므로 시선 차이의 가독성이 판별의 전부"라고 했다. 시선은 좌우 반전 두 값뿐이라 인물·컵 배치에 따라 한 장면에서 구분이 안 될 수 있다. 사흘째 컵 조작 후(자녀는 컵을, 기다리는 이는 플레이어를 바라봄)를 계산하면 다음과 같다.

| 배치 (자녀 / 컵 / 기다리는 이) | 플레이어 위치 | 자녀 시선 | 기다리는 이 시선 | 한 장면에서 읽히는 것 |
|---|---|---|---|---|
| 2.4 / 3.5 / 9.0 (v2 초안) | 기다리는 이의 왼쪽 | 오른쪽 | 왼쪽 | 두 사람이 서로 마주 봄 |
| 2.4 / 3.5 / 9.0 (v2 초안) | 기다리는 이의 오른쪽 | 오른쪽 | 오른쪽 | 둘 다 같은 방향 |
| 5.0 / 3.5 / 9.0 | 기다리는 이의 왼쪽 | 왼쪽 | 왼쪽 | 같은 방향 (대조군) |
| 5.0 / 3.5 / 9.0 | 기다리는 이의 오른쪽 (x≈10.2) | 왼쪽 | 오른쪽 | 서로 등진 모양. 구분됨 |

v2 초안 좌표에서는 자녀가 컵의 왼쪽에 있어 항상 오른쪽을 보므로, 구분이 기다리는 이의 방향이 바뀌는 순간에만 가능하다.

## 결정
1. 사흘째 자녀 위치를 x 2.4 → 5.0 으로 옮긴다(컵 3.5의 오른쪽, 첫날과 같은 자리). 기다리는 이 9.0과 관찰 구역 7.8/10.2는 유지한다.
2. 두 인물의 위치는 고정한다. 판마다 교체는 14주차 이후 선택 기능으로 보류한다(이번 주는 같은 조건의 반복 테스트가 우선).
3. 사흘째 컵 조작 후 기다리는 이 머리 위 "……" 말풍선을 제거한다(외형 단서가 되므로). 손은 송별 단계에서만 나타난다.
4. 프로토타입의 시선 표현은 스프라이트 좌우 반전 + 얼굴 방향 표시로 한다. C3 눈동자 추적은 에셋 해상도 확정 후 재검토한다.
5. 연출 방향: 문자와 설명 대사를 최소로 두고 분위기와 행동으로 진행하며, 결말은 한 화면 문구로 닫는다. story.md 8절의 대사 전량 외에 설명 대사를 추가하지 않는다.
6. 사흘째 시작 시 두 인물은 모두 현관 쪽(오른쪽)을 본다. x 5.0의 자녀가 처음부터 왼쪽을 보면 컵을 움직여도 돌아보는 반응이 보이지 않기 때문이다. 컵을 움직이는 순간 두 사람이 함께 왼쪽으로 돌아서고(같은 반응), 플레이어가 기다리는 이의 오른쪽(x≈10.2)에 서야 기다리는 이만 돌아선다.
7. 5번에 따라 관찰 결과를 글로 알려 주는 문구를 뺀다: "가족은 움직인 컵만 바라보고 있다", "……저 사람은 컵이 아니라 나를 보고 있다", 구역별 "저 사람이…" 안내, "저 사람이 손짓하자 송별불이 꺼졌다". 같은 얼굴이 둘이므로 "저 사람"이라는 지칭도 목표·도움말에서 쓰지 않는다. 날짜 자막은 story.md 8절대로 "8월 13일 밤" / "8월 16일 저녁"만 둔다. 송별·결과 화면 문구는 T5(결과 화면 2종)에서 같은 원칙으로 정리한다.

## 결과
- 자녀 시작 위치는 Inspector의 `familyDay2X` 값 하나로 조정된다.
- 검증: 처음 보는 1명이 설명 없이 둘 중 누가 나를 보는지 구분하는지 플레이테스트로 기록한다.
- 열린 사항: 위 배치로도 구분되지 않으면 컵을 x≈1.0으로 옮기는 안을 재검토한다. 컵과 사진은 서로 다른 단계에서만 활성화되므로 범위가 겹쳐도 충돌하지 않는다.
