# 0006. 서사를 "내가 남의 자리에 들어와 있었다"는 반전 구조로 바꾸고, 결말을 행동으로 갈리는 4종으로 한다

- 상태: 채택 (2026-11-10)
- 대체: ADR 0002(같은 얼굴 두 명), ADR 0003(배웅·남겨짐 2종), ADR 0004의 판별 장면(컵 판별은 첫날 학습으로 축소). ADR 0005의 탑다운·추적·글 최소화는 유지.
- 관련: docs/story.md(v3)

## 맥락
탑다운 프로토타입 1차에서 제작자 피드백: "결말이 너무 단순하다", "잡히고 끝나면 노잼", "남에게 20분 시켰을 때 괜찮다 싶은 수준". 원인은 반전·의미 변화가 없어 결말이 결과 통보에 그쳤다는 점이다.

## 결정
1. 진실: 주인공은 얼굴을 잃은 옛 거주자이고, 쫓아오는 존재가 아이의 진짜 부모다. 불단 사진을 세우는 행동(플레이어가 "내 인사"라고 믿는 행동)이 반전을 연다.
2. 날마다 같은 조작(소리로 아이 부르기)의 쓰임이 바뀐다: 첫날 알리기 → 둘째 날 주의 돌리기(노크 방어) → 마지막 길 이끌기.
3. 붙잡혀도 끝나지 않는다: 문밖으로 내쳐지고, 창·문을 두드려 아이가 열게 해야 들어온다.
4. 결말 4종(배웅·빼앗은 불·남은 자리·꺼진 불)은 반전 이후 행동으로 갈리며 판정은 Core `EndingRule`(EditMode 테스트).
5. 반전 전에는 출구를 막아 1회 플레이에서 반전을 반드시 보게 한다.

## 결과
- 아이 반응 규칙: 벽을 돌아가는 걸음 수 14 이하이면 소리를 듣는다(`GridMap.TryNearestNeighbor`). 마지막 소리 사슬의 각 고리는 12·13·4·12·10걸음으로 범위 안이다(시뮬레이션 확인).
- 위험: 반전 장면(사진 클로즈업)이 설명 없이 읽히는지 처음 보는 사람 테스트로 확인해야 한다. 회색 박스에서는 그것의 "붉은 띠"와 사진의 붉은 옷으로 동일 인물을 표시한다.
- 줄일 곳: 일정이 밀리면 문밖 구간을 "현관에서 다시 시작"으로 줄인다.
