## 이미 정해진 것
- 최종 마감: 2026년 12월 중순. 원안의 4주 일정 대신 약 6주로 재배치한다(`docs/roadmap.md`).
- 중간 GDD와 판별 구조가 달라져도 된다. 게임이 더 나아지는 쪽을 택한다.
- 도트 그래픽은 직접 그리지 않고 이용 조건을 확인한 외부 에셋을 쓴다. 기존 v1의 "128×192 직접 제작" 규격은 폐기하고 에셋 해상도에 맞춰 다시 정한다.
- 기존 주차 실습 코드(PlayerController 등)는 재사용하지 않는다.
- 범위 밖 목록(v1 기준): 마을 탐색, 아홉 시간대, 개와 아이의 인식 규칙, 자유 물리 조작, 추격 AI, 인벤토리, 저장, 안내서 위조, 추가 진엔딩. (2026-11-10 변경: ADR 0005로 한 집 안 여러 방과 그것 1명의 격자 추적은 허용, ADR 0006으로 결말이 4종이 됨. 현재 범위 밖 목록은 CLAUDE.md "작업 방식"이 기준이다.)

## 진단 — v1의 약점
> 측면 시점 v1 기준의 기록이다. 변경 이력의 근거로 남긴다.

### D1. 판별할 대상이 없다
사흘째 실제 가족(x 2.4)과 가짜(x 9.0)는 위치가 다르고, 가짜는 첫날에 없던 인물이다. 플레이어는 컵 실험 전에 이미 "새로 나타난 쪽"을 의심할 수 있으므로 컵 실험이 추리가 아니라 확인 절차가 된다.

### D2. 실패를 선택할 동기가 없다
손잡기 선택창은 거절이 기본이고 Esc로 취소되며, 확정해야만 실패한다. 공정하지만 손을 잡고 싶게 만드는 유인이 없어 대부분의 플레이어는 실패 엔딩을 보지 않는다.

### D3. 시선이 좌우 두 값으로만 표현된다
스프라이트 좌우 반전은 "왼쪽/오른쪽" 두 값뿐이다. 컵과 플레이어가 같은 쪽에 있으면 반응 차이가 사라지며, 차이의 가시성이 플레이어의 위치에 의존한다.

### D4. 공포가 단계적으로 상승하지 않는다
이상 징후 단계는 "컵 조작 → 좌우 관찰 각 1초 → 불 꺼짐"인데, 그 사이에 화면·소리가 점점 이상해지는 장치가 없다.

### D5. 문서 오류 (gdd-v2에서 수정)
- 서론의 인용 [3][4](린노지·교토 자료)는 참고문헌 번호상 [1][2]다.
- 초깃값과 재시작의 [6]은 없는 번호다. LoadScene 문서는 [4]다.
- "최종 제출 형식과 경로는 수업의 별도 안내에 맞춘다[1]"의 [1]은 린노지 자료다. 수업 안내를 참고문헌에 추가하거나 인용을 지운다.
- 본문은 Unity 6.6, 참고 문서 URL은 6000.0 버전이다. 설치된 Editor는 6000.6.0f1이므로 문서 URL 버전을 맞춘다.
- AI 활용 기록에 Claude Code와 사용한 스킬(mattpocock/skills)을 추가해야 한다.

## 후보 — 범위를 크게 늘리지 않는 개선

### C1. 같은 모습의 가족 두 명 (D1 대응)
사흘째에 같은 스프라이트의 인물이 두 명 있다. 하나는 불단 앞, 하나는 방 중앙. 어느 쪽이 진짜인지 외형으로는 알 수 없고, 컵 실험(컵을 보는가, 나를 보는가)이 유일한 판별 수단이 된다.
- 비용: 낮음. 같은 스프라이트를 쓰므로 그림 작업이 줄어든다.
- 그릴링 질문: 두 사람의 위치를 무작위로 바꿀 것인가(재플레이 시 판별을 다시 해야 함), 고정할 것인가? 첫날에도 두 사람을 둘 것인가?
- 연쇄 영향: 관찰 구역 위치, 손잡기 대상 지정, 송별 단계의 실제 가족 이동 경로.

### C2. 가짜만 나를 볼 수 있다는 유인 (D2 대응)
안내서의 "산 사람은 당신을 볼 수 없습니다"와 대비되게, 가짜는 플레이어를 보고 말을 건다(예: 플레이어를 부르는 짧은 대사). "알아봐 주기를 바라던 마음"이 그대로 손을 잡을 동기가 된다.
- 비용: 대사 2~3줄.
- 그릴링 질문: 대사가 몇 번, 어느 시점에 나오는가? 실제 가족이 자녀이므로 가짜도 자녀의 말투를 흉내 내는가?

### C3. 눈동자 추적 (D3 대응)
머리 스프라이트와 눈동자를 분리하고, 바라보는 대상 방향으로 눈동자를 최대 1~2픽셀 이동시킨다. 몸 좌우 반전과 함께 쓰면 같은 쪽에 있어도 시선 대상이 구분된다.
- 비용: 낮음. 눈동자 오프셋 = 대상 방향 벡터를 최대 길이로 자른 값.
- 그릴링 질문: 외부 에셋 인물에서 눈동자를 분리할 수 있는가(에셋 해상도에 의존)? 불가하면 머리만 별도 스프라이트로 기울이는 대안.

### C4. 관찰 진행도에 따른 이상 연출 (D4 대응)
사흘째 관찰 진행도를 조건으로 단계적 변화를 준다. 예: 관찰 0 → 정상, 한 구역 완료 → 사진 속 얼굴이 흐려짐, 두 구역 완료 → 벌레 소리가 끊긴 직후 불이 꺼짐.
- 비용: 소품 상태 1개, 소리 정지 연출.
- 그릴링 질문: 변화 단계 수, 각 단계의 연출, 실제 가족 쪽 반응 유무.

### C5. 결말의 여운
성공: 귀환 후 마지막 컷에 가짜가 여전히 방 안에 남아 있음. 실패: 결과 화면에 그 집의 이후를 암시하는 한 문장.
- 비용: 컷 1장, 문구 1줄.

### C6. 안내서 문구를 규칙 괴담 형식으로 다듬기
안내서 위조는 범위 밖이므로 규칙 자체는 바꾸지 않는다. 처음엔 평범하게 읽히던 규칙이 사흘째에 의미를 갖도록 문구와 순서만 다듬는다.
- 그릴링 질문: 규칙 개수와 문체, 안내서를 처음 여는 시점을 강제할 것인가.

### C7. 기다리는 망자 서사 (D2·D4와 결말 전체에 영향)
상세는 `docs/story.md`. 가짜를 "불을 피워 줄 사람이 없어 남의 마중불을 따라 들어온 옛 거주자"로 재정의하고, 얼굴 규칙(C1의 근거), 옛 사진·기둥 눈금·낡은 등롱 단서, 성공 2갈래(귀환/배웅)+실패 결말을 둔다. C1·C2·C5·C6과 함께 결정해야 한다.

## 에셋 규격 (그릴링에서 확정)
> 아래는 v2 측면 시점 기준이라 탑다운에는 맞지 않는다. 현재 House 씬은 지도 한 칸 = 1유닛, 카메라 orthographicSize 6(세로 12칸)이므로 1280×720에서 한 칸이 60px이다. 탑다운 타일·인물 규격과 필요 목록(소품·효과음)은 에셋 방향이 정해진 뒤 다시 쓴다.
- 기준: 1280×720 화면, 세로 9유닛. 레퍼런스 해상도 640×360이면 PPU 40, 인물 64~72px. 320×180이면 PPU 20, 인물 32~36px.
- URP 2D Pixel Perfect Camera로 정수 배율 확대(1280×720=2배, 1920×1080=3배 at 640×360).
- 순서: 인물 에셋 크기를 먼저 정하고, 같은 해상도 계열의 배경·소품을 고른다. 해상도가 다른 팩을 섞지 않는다.
- 필요 목록: 일본식 목조 실내(다다미, 미닫이, 불단)와 현관, 성인 인물 1종(가족·가짜 공용) + 망자 1종, 컵·액자·풍경·불·정령마 소품, 한글 픽셀 글꼴 1종, 효과음 5종(컵 마찰, 액자 받침, 풍경 종, 점화, 소화), 환경음 1종(여름 저녁 벌레 소리), UI 패널·버튼.
