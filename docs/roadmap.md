## 열린 질문 (학생이 정할 것)
1. (해결, 2026-11-11) 반전 후 선택창의 기본값과 Esc. 첫 항목이 기본값이자 Esc의 결과인데 첫 항목이 "비켜선다"여서, Esc나 E 한 번으로 남은 자리 결말이 확정됐다. 순서를 "그대로 있는다 / 비켜선다"로 바꿔 기본값과 Esc가 아무 일도 일으키지 않게 했다. 반대로 두고 싶으면 `HouseFlow.Interact`의 `ui.Choose` 호출 한 곳만 바꾸면 된다.
2. **성공·실패 조건.** 수업 가이드는 성공·실패 조건을 요구한다. 결말 4종 중 무엇을 실패로 볼지(예: 꺼진 불만 실패, 또는 "실패 없음, 결과 분기"로 설명). 교수님 확인 질문 5와 함께.
3. **아트 방향.** 외부 탑다운 타일셋·인물 에셋으로 바꿀지, 지금의 도형 스타일을 다듬어 쓸지. 바꾼다면 규격(한 칸 픽셀 수, Pixel Perfect Camera 여부; 지금은 한 칸 = 60px at 1280×720).
4. **소리.** 코드 생성 소리를 유지할지, 외부 효과음으로 바꿀지.
5. **시작·종료 화면.** 지금은 바로 오프닝이 시작되고 결말 화면에서 R로만 다시 시작한다. 타이틀 화면, 일시정지(Esc), 게임 종료 키가 필요한지.
6. **안내서(C6).** v1의 귀성 안내서(Tab)는 v3에 없다. 다시 넣을지, 폐기할지.
7. **한글 글꼴.** OS 글꼴에 기대는 지금 방식을 유지할지, 글꼴 파일을 프로젝트에 넣을지(이용 조건 기록 필요).
8. **미니맵 목표 표시 범위.** 첫날에는 목표를 표시하지 않는다. 처음 보는 사람이 첫날에 막히면 첫날에도 표시할지. (3인 테스트 후 결정해도 됨)
9. **영상에 담을 결말.** 한 판 영상에 어떤 결말을 보여 줄지.
10. **측면 프로토타입 처리.** `Mukaebi.unity`와 `Assets/Scripts/` 바로 아래 v1 스크립트를 최종 프로젝트에 남길지, 별도 폴더로 옮기거나 지울지.
