# 마중불 로드맵 (수업 주차 기준)

> 주차 날짜는 9월 1일 개강 기준 추정(16주차 = 12/14~18). 수업 공지와 다르면 날짜만 옮긴다.
> 이전 계획 대비: 1주차(11/2~8) 그릴링은 진행되지 않았고, 대신 v1 기준 프로토타입(GameFlow 등)이 만들어졌다. 서사 결정 2건은 ADR 0002·0003로 기록했다.

## 스킬 흐름
1. `/grill-with-docs` — 남은 결정(아래) → ADR, GLOSSARY.md
2. `prototype` — 필요 시 시선 가독성 HTML 비교 (Unity 프로토타입으로 충분하면 생략)
3. `research` — 에셋 후보·이용 조건 → `docs/research/assets.md`
4. `/to-questionnaire` — course-requirements.md 하단 질문
5. `docs/gdd-v2.md` 작성 → `/to-spec`(검증 표 = 수용 기준) → `/to-tickets`
6. 티켓마다 `/implement` (Core는 tdd, 마지막 code-review), 버그는 `diagnosing-bugs`
7. 세션이 길면 `/handoff`, 주말마다 `/retro`

## 11주차 그릴링에서 정할 것
1. 같은 얼굴 2명의 배치: 고정 / 판마다 좌우 교체
2. 옛 사진 위치: 기다리는 이가 서는 문 앞 근처(접근이 무섭지만 안전한 선택) / 불단 / 장지문 위
3. 시선 표현(C3): 인물 해상도 기준의 조건부 결정
4. 이상 연출(C4) 단계 수와 내용
5. 에셋 규격: 레퍼런스 해상도·PPU
6. 기존 프로토타입의 v1 상수(x 좌표 등)를 v2에서 어떻게 바꿀지
